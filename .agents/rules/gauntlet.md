# Gauntlet Loop Rules

Quando acionado para tarefas de alta exigência, design, frontend, refatoração ou construção de features:
1. Nunca encerre uma tarefa no estado "bom o suficiente" sem validar contra uma barra real.
2. Utilize a divisão Builder-Critic.
3. Subagentes disponíveis para o Gauntlet:
   - \uilder\: Implementador e refatorador de código/UI.
   - \design-critic\: Avaliador implacável de UI/UX, tipografia, contraste e layout comparativo.
   - \unctionality-critic\: Avaliador de edge cases, integridade lógica, fluxos e bugs.
   - \code-quality-critic\: Avaliador de boas práticas, segurança, tipagem e arquitetura limpa.
